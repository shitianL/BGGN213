# Class 08 — Machine learning I

Introduction to unsupervised learning: clustering and dimensionality
reduction, and how to tell when each is telling you something real.

Covers:

- **k-means** (`kmeans()`) — choosing `centers`, why `nstart` matters
- **Hierarchical clustering** (`hclust()`) — linkage and cutting the tree
- **PCA** (`prcomp()`) — score plots, loadings, variance explained

Worked on the UK food consumption dataset, where PCA makes the outlier
country obvious in a way the raw table does not.
