# Class 05 — Data visualization with ggplot2

The grammar of graphics: mapping data to aesthetics, choosing geoms, and
layering. Works through the `gapminder` life-expectancy data and builds up
from a basic scatter plot to faceted and interactive versions.

| File | Purpose |
| --- | --- |
| `class05.Rmd` | Source |
| `class05.md` | Rendered Markdown — displays directly on GitHub |
| `class05.R`, `class05.pdf` | Script and PDF |
| `class05_files/` | Figures for the Markdown render |

Geoms used: `geom_point()`, `geom_smooth()`, `geom_violin()`, `geom_jitter()`.
Packages: `ggplot2`, `gapminder`, `plotly`.
