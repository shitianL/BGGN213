# 1st Year Exam — Q15

A `ggplot2` exam question worked through: plotting the share of SARS-CoV-2
variants circulating in California over time.

| File | Purpose |
| --- | --- |
| `ggplot.Rmd` | Source |
| `ggplot.html`, `ggplot.pdf` | Rendered output |
| `covid19_variants.csv` | Variant frequencies by date |

Uses `ggplot2` with `geom_line()`, `dplyr` for reshaping, and `scales` for
axis formatting.
